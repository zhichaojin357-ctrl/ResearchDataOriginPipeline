# Manual Calibration Entrypoint

Manual review starts from products generated by the formal pipeline. Do not use archived one-off exemplar folders as the source of truth.

## Product Sources

Use the newest successful run under the external output root:

- `../输出/runs/<timestamp>_template_format_*`
- `../输出/runs/<timestamp>_xrd_*` for dedicated XRD overlay products
- `../输出/reports` for queue, readiness, validation, and audit reports

Each accepted Origin product must include:

- `.opju` project
- 600 dpi `.tif` export
- preview image when generated
- `metadata.json`
- run-level summary and label/path audit reports

## Recommended Review Order

1. XRD
2. XPS in-situ
3. XPS non-in-situ
4. EPR
5. BET
6. EIS
7. photocurrent
8. Mott-Schottky
9. UV-vis DRS / Tauc
10. PL
11. FTIR
12. Raman
13. reaction condition screening
14. HPLC/LC calibration and exported LC data

## Checks

Confirm that workbook names show only the data filename, workbook comments are blank, and no visible label or metadata field contains an automation/tool name or an absolute local path. Scientific interpretation must stay in `manual_check_required` fields unless the user has explicitly supplied and reviewed that interpretation.
