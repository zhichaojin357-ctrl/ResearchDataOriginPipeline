## Global Acceptance Rule

An output is not manuscript-ready until:

1. the data source is approved for the specific goal;
2. the processing path uses formal project entry points;
3. generated artifacts are reviewed under an explicit artifact/Origin goal;
4. visual acceptance is recorded;
5. scientific claims remain manual or explicitly evidence-backed.
