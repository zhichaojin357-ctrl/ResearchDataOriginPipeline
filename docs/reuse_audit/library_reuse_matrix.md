## Core Package Notes

Core dependencies are deliberately small:

- `pandas`, `numpy`, `scipy`, `openpyxl`, `PyYAML`: standard table/config/numeric stack.
- `pybaselines`: reusable baseline correction for FTIR/Raman/EPR/PL style spectra.
- `originpro`, `pywin32`: OriginPro automation and Windows COM support. OriginPro itself is preinstalled and must not be installed by this project.

## Optional Package Notes

Optional packages are command- or format-specific extras, diagnostic adapters, or future discovery items. They should only be imported behind the relevant command or adapter boundary. Missing extras must not break `--help`, `deps-audit`, `scan`, or unrelated processors. Agilent OpenLab `.dx` production decoding and default stored-`.rx` mode are project-native and do not require `rainbow-api`, OpenLab, MestReNova, or a `.pmx` runtime. The explicitly requested `--vendor-reprocess` mode is the sole exception: it uses the project-bundled, hash-verified Agilent Processing Server runtime and complete PMX method by default, and fails closed if that bundle is unavailable or altered. Explicit complete runtime overrides remain supported for controlled comparison. `rainbow-api` and MOCCA2 remain optional validation/benchmark tools and their absence must not change production results.
