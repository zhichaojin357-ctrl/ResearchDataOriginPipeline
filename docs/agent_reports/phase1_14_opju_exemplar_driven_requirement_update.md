# Phase 1.14 OPJU Exemplar-Driven Requirement Update

## Updated Requirement

The local processed OPJU exemplars are now the requirement source for Origin regression testing.

The project must compare:

1. The human-prepared OPJU exemplar or its exported graph pages.
2. The OPJU/TIF/PNG generated by the project scripts for the corresponding data.
3. The processing route used to generate the plotted data.

Image existence alone is no longer sufficient. A generated figure that is nonempty but uses the wrong processing route, graph grouping, curve roles, or OPJU page target is a regression failure or warning.

## Comparison Rules

- Use copied OPJU exemplars under `output/opju_exemplar_regression/reference_opju` as safe local references.
- Use exported exemplar graph pages under `output/opju_exemplar_regression/reference_exports` for visual comparison.
- Preserve F-drive files as read-only.
- Compare OPJU intent before judging style:
  - graph/page family,
  - number of scientifically relevant graph outputs,
  - curve roles,
  - plot primitive,
  - axis line/tick/tick-value policy,
  - legend frame or direct-label policy,
  - template residue,
  - forbidden claims.
- Then compare style:
  - Graph4 geometry,
  - fixed fonts and bold text,
  - axis and curve width,
  - material/sample colors,
  - output OPJU/TIF/PNG existence.

## EPR Correction

The previous EPR regression item was wrong because it compared a single decoded raw EPR trace against a human OPJU that contains condition-group overlays.

The required project output is now:

- `run.py epr-overlay --group all --with-origin --force`
- `output/origin_files/EPR_OH_overlay.opju`
- `output/origin_files/EPR_O3_overlay.opju`
- `output/figures_tif/EPR_OH_overlay_8d3e95bb.tif`
- `output/figures_tif/EPR_O3_overlay_895a7063.tif`
- `output/figures_preview/EPR_OH_overlay_8d3e95bb.png`
- `output/figures_preview/EPR_O3_overlay_895a7063.png`

These must be compared against:

- `output/opju_exemplar_regression/reference_exports/opju_exemplar_08_EPR/ohG.tif`
- `output/opju_exemplar_regression/reference_exports/opju_exemplar_08_EPR/o3G.tif`

The processing record must state:

- JEOL verified 4096-point export is the default only for verified JEOL cAcqu raw files.
- Overlay plotting does not force all EPR input to be 4096 points.
- Baseline correction uses edge-region median subtraction.
- Smoothing is optional and disabled by default.
- Background subtraction is optional and only allowed with explicit matched dark/background mapping.
- Normalization is optional and disabled by default.
- No radical or mechanism assignment is made.

## Script Change

`scripts/maintenance/opju_exemplar_regression.py` now supports contracted OPJU comparison items. For EPR, it expects the overlay OPJU pair rather than the old single `process --with-origin` result.
