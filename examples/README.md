# Examples

Small examples and usage notes for the pipeline. Raw project data is not stored here.

## Contents

- `ll_drs_pairing.json`: explicit four-sample Hitachi U-3900 DRS pairing;
  see `docs/method_cards/uvvis_drs.md` for data-only and Origin commands.
- `ll_drs_tauc_pairing.json`: three named DRS samples plus BOB/BVO Tauc edge
  intervals and repeat-selection provenance; `--uvvis-bundle` produces one
  editable project containing the two graph pages.
