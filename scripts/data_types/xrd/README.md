# XRD Scripts

XRD-specific scripts live here only when they are tied to reviewed XRD plotting workflows that cannot be represented by a generic table processor alone.

Current scripts:

- `plot_xrd_no_card_overlay_origin.py`: builds a no-card, multi-curve XRD overlay from a reviewed CSV, applies the accepted reference OPJU style, exports OPJU/PNG/TIF outputs, and writes metadata plus a short report.
