# One-off Scripts

One-off migration, audit, or report-generation helpers should live here when they are intentionally kept for traceability.

Prefer writing produced reports under the configured output root and documenting reusable behavior in source docs only when it becomes part of the maintained workflow.

Current scripts:

- `verify_jeol_epr_decode_against_exports.py`: retained one-off JEOL EPR raw decode verification helper.
